1. Introduction

This project analyzes the relationship between world population growth and CO2 emissions. It uses population and CO2 emissions datasets to explore population trends, examine CO2 emission patterns, and investigate the relationship between population size and CO2 emissions using statistical analysis and data visualization.

Dealing with outliers

numeric_data <- population[, sapply(population, is.numeric)]

count_outliers <- function(x) {

  Q1 <- quantile(x, 0.25, na.rm = TRUE)
  Q3 <- quantile(x, 0.75, na.rm = TRUE)

  IQR_value <- IQR(x, na.rm = TRUE)

  lower <- Q1 - 1.5 * IQR_value
  upper <- Q3 + 1.5 * IQR_value

  sum(x < lower | x > upper, na.rm = TRUE)
}
outlier_counts <- sapply(numeric_data, count_outliers)
